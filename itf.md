# Bismillahi rrahmani rraheem
## 1. Technology
Technology is the application of scientific knowledge to make life easier.
## 2. Information technology
Information technology is the use of the application of scientific knowledge used to make computing devices to create, process, store, secure and exchange all the forms of electronic information.
## 3. Computing devices
Computing devices are electronic devices containing a CPU.
Examples of computing devices:
- Desktop computers
- Laptops
- Mobile phones and tablets
- Smart TVs
- Printers
- Security cameras
- Routers and modems.
## 4. Hardware
Hardware is the physical, tangible components of a computing device.
## 5. Softawre
Software is a set of instructions to the hardware to perform a task(s), like video and photo editing, making documents, and playing video.
## 6. Hardware components of computing devices
The main hardware components of some computing devices are:
1. **CPU (Central Processing Unit)**: the component that processes instructions.
2. **RAM (Random Access Memory)**: the short-term memory of the computing device. It is used to run all software on the computing device. It is not persistent.
3. **HDD and SSD (Hard Disk Drives and Solid State Drives)**: the long-term storage of the computing device. It is persistent.
4. **NICs (Network Interface Cards)**: the component that allows the computing device to connect to networks.
5. **GPU (Graphics Processing Unit) or Graphics Card**: the component used to accelerate video operations on the computing device.
There are other harware components, such as the power supply, the cooling fans, the USB interfaces, etc.
## 7. Units
Units are helpful for determining the capability of computing devices.
- CPU speed is measured in GHz.
- Memory is mesured in Bytes.
- NICs speed is measured in Bps (Bytes per second). Usually measured in MBps and GBps.
## 8. Operating systems
Operating systems are software that:
- manage hardware resources (CPU, RAM, HDD or SDD)
- runs installed programs
- handles files and permissions
- provides a user interface (GUI or CLI)
- keeps the hardware and software in harmony.
Examples of operating systems:
- Windows
- MacOS
- Linux
## 9. GUI and CLI
**GUI**: you use the mouse, windows, and icons to use your computing device.
**CLI**: you type commands on to a black screen called the *terminal* to do stuff.

## 11. Open source software
A software is open source when its developer makes the source code of the software open to everybody, where they can see it, make changes and contribute to it, and share it -- for free.
Example of open source software:
- Linux
- OBS Studio
- Vim, etc.
## 12. Applications
Applications are software designed to do a specific task.
Types of applications are:
- **Desktop applications**: run on desktop computers and laptops.
- **Mobile applications**: run on mobile phone and tablets.
- **Web applications**: run on the browser. They can be used by both mobiles devices and desktop computers.
- **Cloud applications**: run on the cloud, includes some web and mobile applications like zoom, slack, etc.
## 13. Physical (Bare-metal) servers
Physical servers are just computers, usually built using powerful hardware such as:
- Big amount of RAM (up to 1TB! The RAM sticks come in large amounts such as 128GB!) and disk storage (They have what's called a cabinet which can hold over 16 HDDs!)
- One or more CPUs, GPUs, NICS
Important things to know about physical servers:
- Operating systems and software applications are installed on servers.
-Physical servers can support a number of users depending on its' hardware specifications
- Any desktop computer or laptop can be turned into a server, although desktop computers and laptops are for personal use, rather than handling the tasks of servers, which require powerful hardware. And physical servers have better hardware than normal PCs and laptops
- The computing devices using the server -- for a particular service -- are called *clients*, and thus this model of communicating and sharing is called the *client-server* model
- Physical servers are built for durability, longevity, and working for long periods
- Phyical servers are very important as they provide a multitude of services, like:
	- Providing access to web applications (web servers)
	- Sharing its extensive amount of resources to its clients over a network (computing servers)
	- Holding databases (database servers), etc.
## 14. Virtualization   
Virtualization is the virtual division of a physical server into multiple virtual servers. This process is done by a special software called the *hypervisor*.
Virtualization has numerous benefits:
- It allows a physical server to run multiple operating systems
- It allows the usage the resources of the physical server to their full potential
- It allows saving money on the physical servers -- by using the ones you have to their full potential, also by not needing to dedicate multiple servers for multiple operating system --, on hardware, on floor space, on maintenance and on electricity
- It facilitates backing up (VMs -- Virtual Machines -- are just software files that can be backed up and uploaded on multiple physical servers)
- It facilitates the management of the physical servers
- It facilitates portability (VMs can easily be transferred to different physical servers).
Hypervisors come in two types:
- **Type 1**: this type is installed on empty, bare metal hardware, meaning there is no operating system, nor any software applications on the machine
	- Examples: VMware vSphere, Microsoft HyperV
- **Type 2**: this type is installed an existing operating system
	- Examples: Oracle VirutalBox, VMware Workstation.
## 15. Data centers
A data center is a physical building containing a number of physical severs contained in cabinets, with the necessary conditions (air-conditioning, cooling, redundant electricity, security, etc.) for 24/7 operation of the physical servers
There are two types of data centers:
- **Vendor controlled data centers**: data centers of owned by companies that offer the use of their physical servers' services and resources in return for money.
	- Examples: AWS, Azure, GCP, Alibaba, IBM
- **On-Premises, or costumer-controlled data centers, also called CAPEX (Capital Expenditure) Model**: owned and mainted by a private company. They handle everything: the network, storage, hardware, virtualization, os, middleware, runtime, data, and applications.
## 16. The Cloud
The cloud is just a fancy name of data centers and the services they provide, such as storage of your personal files on their physical servers (cloud storage), or using their physical server's hardware resources to preform actions -- such as hosting a website, or computing or processing data, etc. -- (cloud computing), etc. These services can be accessed via web, mobile, or desktop applications. These services are sold by *cloud providers*, which are the same as the companies mentioned in the previous section. This is called the OPEX (Operational Expenditure, pay-as-you-go, you pay what you use) Model.
## 17. Services provided by cloud providers
The services provided by cloud providers are:
- **Infrastrucre as a Service (IaaS)**: the cloud provider only takes care of the physical servers that the client rents, alongside the networking, and virtualization
- **Platform as a Service (PaaS)**: the cloud provider handles the hardware and some of the software, such as the operating system, middleware, and runtime
- **Software as a Service (Saas)**: the cloud provider handles everything -- the hardware and the software.
## 18. Private vs. Public cloud
The public cloud:
- Resources are publicly shared
- Shared infrastructure
- Accessed via the internet
- Best suited for less personal data
The private cloud:
- Resources are for private use
- For a single costumer, or for specific companies
- Accessed over fiber, private networks and the internet
- Best suited for personal, confidential data
## 19. Hybrid cloud
A hybrid cloud can be approached, where a client use both the public cloud, and has a private cloud of his own.
## 20. Multi cloud
Multi cloud is the use of different cloud services from different cloud providers, as one can be better at a task than the other.
## 21. Hybrid-Multi cloud
Using both a multi cloud and hybrid cloud approach is called a Hybrid-Multi cloud.
## 22. Network
A network is simply two or more connected computing devices to share data (be it files, images, videos, software, etc.).
- The computing devices mentioned in the first sections can be connected to a network.
- Each computing device on a network must have an IP (Internet Protocol) address to make it reachable.
The different type of networks are:
- **LAN** -- Local Area Network
- **WLAN** -- Wireless Local Area Network
- **WAN** -- Wide Area Network
- **CAN** -- Campus Area Network
## 23. LAN
LAN is a network of connected computing devices by cables in a small area--like a home, school, office, building--so they can share files and communicate or use the internet.
## 24. WLAN
WLAN is just a wireless, cableless LAN.
## 25. WiFi
WiFi is a wireless communication technology that allows computing devices to communicate wirelessly using a router that recieves information in the form of radio waves and passes them to the correct computing device.
WiFi is what allows a wireless connection to the internet. WiFi is not the internet.
## 25. WAN
WAN is a network that allows computing devices seperated by large distances (across cities, countries, continents) to communicate with eachother.
## 26. Types of traffic (data) flow
**Unicast/One-to-One**: data goes from a single computing device to another
**Multicast/One-to-Group**: data goes from a single computing device to many computing devices, but not all
**Broadcast/One-to-All**: data goes from a single computing device to all the computing devices on the network
## 27. Wired network devices
**Hub**: connects multiple computing devices in LAN (computing devices are wired to the hub, instead of each computing device being wired to eachother)
Disadvantages of the hub are:
	- Sends data to all connected devices
	- All the computing devices recieve the same bandwidth
	- Slower and less secure.
**Switch**: basically a hub but better and smarter.
Advantages of the switch are:
- Sends data to specific computing devices
- Each connection can use the full speed of the port it is connected to
- Faster and more secure.
